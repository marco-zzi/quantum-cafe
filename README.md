# Quantum Café: Interactive Apps

Welcome to the open-source repository for the **Quantum Café** interactive visualization suite, developed for Vilnius University (VU) and the Lithuanian Quantum Technologies Association (LKTA).

This repository contains lightweight, interactive web applications built with Python and Streamlit, featuring isometric animations designed to demystify quantum computing concepts during public engagement events and hackathons.

## Applications Included
1. **Programmable Quantum RNG**: An interactive tavern-themed table where users rotate 8 independent quantum coins to generate a random byte.
2. **Vilnius Teleportation Link**: A city-map visualization tracking entanglement distribution across university locations with a simulated eavesdropper.
3. **Satellite Superdense Coding**: An orbital LEO satellite link demonstrating information capacity scaling.
4. **Quantum Jigsaw Solver**: A comparative speed benchmark between manual trial-and-error and quantum variational classifier.
